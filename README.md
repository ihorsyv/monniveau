# Niveau FR — тест на уровень французского

Адаптивный тест французского языка (A1 → A2 → B1) с переводом и произношением.
Работает полностью в браузере, без сервера и базы данных — статический сайт на чистом HTML/CSS/JS.

Продакшн: **https://monniveau.netlify.app**

## Что это

- 🇫🇷 Три последовательных блока по 40 вопросов: **A1**, **A2**, **B1**.
- После каждого блока — порог прохождения (`GATE` в коде): не набрал процент правильных ответов — тест завершается на этом уровне и показывает разбор ошибок, вместо перехода дальше.
- К каждому вопросу — объяснение грамматики, перевод фразы на русский и (где применимо) кнопка **🔊 Слушать произношение** через `SpeechSynthesis` API браузера.
- Прогресс сохраняется в `localStorage` — при перезагрузке страницы тест продолжается с того же места.
- Можно установить как приложение на главный экран телефона (PWA, см. ниже).

## Технологии

Никакого фреймворка и сборки. Один HTML-файл:
- Вёрстка и стили — инлайновый `<style>`.
- Логика — инлайновый `<script>` (~400 строк vanilla JS).
- Данные вопросов — массив `BLOCKS` прямо в коде (`index.html`).
- Озвучка — `window.speechSynthesis` (голос `fr-FR`, если доступен в браузере).

## Запуск локально

Открыть файл напрямую (`open index.html`) можно, но `manifest.json` через `file://` браузеры подгружают не всегда корректно — надёжнее поднять локальный сервер:

```bash
cd monniveau
python3 -m http.server 8765
open http://127.0.0.1:8765/
```

## Деплой

Сайт на **Netlify**, подключён к этому GitHub-репозиторию (`ihorsyv/monniveau`, ветка `main`).
Настройки на Netlify: build command — пусто, publish directory — `.` (корень репозитория).

Деплой — автоматический: любой `git push` в `main` запускает публикацию на https://monniveau.netlify.app.
Ручной деплой (в обход git), если понадобится: `netlify deploy --prod --dir=.`

## Как устроены вопросы

Каждый вопрос в `BLOCKS` — объект вида:

```js
{ q: "Je ___ étudiant.", o: ["est","suis","es","sommes"], a: 1, t: "Être",
  e: "Глагол être: je → SUIS...", tr: "Я студент." }
```

- `q` — текст вопроса (`___` — пропуск для заполнения);
- `o` — варианты ответа;
- `a` — индекс правильного варианта;
- `t` — тег темы (показывается на карточке);
- `e` — объяснение;
- `tr` — перевод (опционально).

Кнопка озвучки показывается, если из вопроса можно однозначно извлечь французскую фразу (сам вопрос с заполненным пропуском, текст в «кавычках-ёлочках», либо правильный вариант ответа, если он не на русском) — см. `speakTextFor()` в `index.html`.

## Известные особенности / ограничения

- Прогресс живёт только в `localStorage` конкретного браузера на конкретном устройстве — не синхронизируется между устройствами (нет аккаунтов и бэкенда, и осознанно не планируется без явной причины).
- Озвучка зависит от того, какие голоса доступны в браузере/ОС пользователя — на части систем французского голоса может не быть.

## История значимых изменений

- **Исправлена кнопка озвучки** — она ломалась на вопросах, где французская фраза содержала апостроф (`j'ai`, `c'est`, `l'école`...), потому что текст подставлялся прямо в HTML-атрибут `onclick='...'` в одинарных кавычках, и апостроф преждевременно закрывал атрибут.
- **Добавлено сохранение прогресса** между визитами через `localStorage`.
- **Добавлена поддержка PWA** — `manifest.json` и иконки 192/512, чтобы сайт можно было установить на главный экран.
- **Настроен автодеплой** с GitHub на Netlify.
